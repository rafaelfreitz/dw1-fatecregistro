Vantagens do CSS Externo

  • Separação completa entre conteúdo (HTML) e design (CSS)
  • Reutilização em múltiplas páginas
  • Facilita manutenção do código
  • Melhor organização do projeto
  • Pode ser armazenado no cache do navegador, melhorando a performance
